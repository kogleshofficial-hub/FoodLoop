# FoodLoop 🌍🍱

**Give surplus food another chance. Share more. Waste less.**

FoodLoop is a real-world food-rescue web app designed to connect people with surplus food that would otherwise go to waste. Donors can publish available food, while other users can discover listings and request a pickup. Donors remain in control of who can collect their food.

## What FoodLoop does

- 🔎 Discover available surplus food
- 📍 Browse food by location
- 🍱 Publish surplus food with pickup details
- 🙋 Request food from another user
- ✅ Donors can accept or decline requests
- 🗑️ Donors can delete their own listings
- 🔐 Supabase Authentication and Row Level Security
- 📱 Responsive experience designed for mobile and desktop
- 🌍 Built with a worldwide audience in mind

## Product principles

FoodLoop is intentionally built around **real data and real actions**. Listings, accounts and requests are stored in Supabase rather than simulated with placeholder content. Security rules prevent users from managing data they do not own, and users cannot request their own food.
